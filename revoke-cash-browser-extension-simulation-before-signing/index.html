Revoke.cash Browser Extension: Simulation Before Signing

What does the revokecash browser extension do? It simulates proposed transactions and warns before signing; use the site to review and revoke old allowances.

The Chain Times DeskNov 17, 2026 · 01:50 UTC3 min read

The revokecash browser extension simulates proposed transactions and warns you before you sign; to remove an allowance already granted, you need an onchain revocation.

What does revokecash browser extension do?

The extension reviews activity your wallet is being asked to approve. Its documentation describes transaction simulation, which previews expected token movements and permission changes before signing, plus an approval checker for reviewing permissions.

Those are two separate jobs. Simulation looks at a proposed transaction. An allowance is permission a wallet has already given a smart contract to spend tokens. Rejecting a new approval request prevents that request from being signed, but leaves any older allowance intact.

Say you visit a site for an NFT mint and the wallet request asks for broad spending permission. Read the proposed spender—the contract that would receive permission—and the scope of the allowance. If the request is broader than you want, reject it. That stops the new permission from being granted; it does not clean up an older one.

For existing permissions, the revokecash website provides an approval-management workflow. The Revoke.cash approval checker helps you review what your wallet has granted, and the site is where you can submit a revocation. That is the difference between stopping a proposed change and changing an allowance that already exists.

  • Transaction simulation: previews expected token movements and permission changes before you sign.
  • Approval checker: helps you inspect permissions already granted to spenders.
  • Onchain revocation: changes an unwanted existing allowance through a wallet-authorized transaction. ERC-20 allowances change through approve transactions.

To clean up an unwanted existing allowance, use the revokecash website, select the network where that permission applies, and submit a wallet-authorized revocation. The linked revokecash site is relevant here because it handles that approval-management workflow.

Using the extension as if rejecting a new prompt also removes old permissions is the wrong move: the older allowance remains. Review and revoke it separately when you want to remove it.

Related

Where to download revokecash extension?

Follow the official website’s extension link to its browser-store listing. That takes you to the listing for the extension you want.

Does revokecash extension replace my wallet?

No. Your existing wallet remains the transaction signer. The extension reviews proposed activity; your wallet still signs transactions, including a revocation.

Use the extension when you want to inspect a transaction before signing. Use the website when you want to review and remove an existing allowance. That distinction tells you whether to reject a request now or submit a revocation to change a permission already in place.
