EVM Compatibility: What Carries Across Chains

What does EVM compatible mean for a blockchain? It means Ethereum contracts, wallets and addresses can work across chains that run the Ethereum Virtual Machine.

The Chain Times DeskNov 24, 2026 · 06:43 UTC3 min read

EVM compatible means a blockchain runs the Ethereum Virtual Machine, so Ethereum contracts, wallets and address formats can work on it.

What EVM compatibility carries across chains

The Ethereum Virtual Machine runs contract code. An EVM-compatible chain can run the same bytecode, so contracts written in Solidity can be deployed there. Each chain still has its own network and balances.

  • Contracts: Solidity code can run on Ethereum, Arbitrum, Optimism, Polygon and BNB Chain, though each deployment is separate.
  • Wallet address: One MetaMask address can be used on those EVM chains because they share an account format and signing method.
  • Gas: Transactions need the chain’s gas token. Arbitrum and Optimism use ETH, Polygon uses POL, and BNB Chain uses BNB.

Say you want to move a token from Arbitrum to Polygon. Your address format may be the same, but the balances stay on their own chains. Use a bridge such as cBridge to transfer supported assets between networks through pooled liquidity or token mappings.

That shared address does not mean every token is on every chain. A token sent to your address on the wrong EVM chain stays under the key for that address, on the chain where it was sent. Switch your wallet to that chain to see and move it; you will need that chain’s gas token to make a transaction.

Take a wallet set to Ethereum while you receive tokens at the same address on Arbitrum. The tokens are on Arbitrum, so switch the wallet network to Arbitrum to view them. Suppose instead they arrive at that address on Ethereum: the key still controls the address, but the tokens are on Ethereum. What carries across is the address and signing key; the balance depends on the chain used.

In everyday use, EVM compatibility lets you reuse a wallet and familiar contract tools across several networks. It also means you must check the selected network before sending or searching for a balance. When funds need to move between chains, cBridge can handle supported assets; the bridge transfer is a separate step from simply switching networks.

Related questions

These questions clarify how EVM compatibility compares with other chain designs.

Is Solana EVM compatible?

No. Solana is not an EVM chain and uses a different address format, so Ethereum accounts and contracts do not carry over in the same way.

What is the difference between EVM compatible and EVM equivalent?

EVM compatible means a chain supports the Ethereum Virtual Machine and its contracts. EVM equivalent describes a closer match to Ethereum’s behavior. Compatibility lets familiar code and tools work, while equivalence concerns how closely execution matches Ethereum.
