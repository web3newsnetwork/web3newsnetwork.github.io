Polygon Bridge withdrawals: how to check a stuck transfer

A stuck Polygon withdrawal may need a wallet confirmation, a retry or a manual exit; check the transaction record before signing anything again.

The Chain Times DeskOct 23, 2026 · 06:10 UTC3 min read

If a Polygon withdrawal looks stuck, check its transaction status before retrying: the funds may be waiting for a wallet confirmation, or the bridge may need you to complete the exit. Polygon Support says a pending transaction can also be held up by low gas, a surge in Ethereum fees or a transaction replaced in your wallet. The right next step depends on which part of the transfer has finished.

How do I find where the withdrawal stopped?

Open the transaction history in Polygon Portal and note the transaction hash, a unique ID you can search on a block explorer. Check whether the transaction completed on Polygon and whether a matching step has completed on Ethereum. Polygon Support describes the return transfer as burning the Polygon-side tokens before the Ethereum-side tokens are unlocked. If the Polygon transaction is still pending, the bridge has not reached the exit step.

For a fuller walkthrough of Polygon Bridge withdrawal steps, see this guide; here, the key is to identify the last completed step first. A completed source transaction with no Ethereum receipt points to a different issue from a transaction still waiting in your wallet.

What should I try if the wallet transaction is pending?

Polygon Support says low gas, Ethereum congestion or a cancelled or replaced transaction can leave a withdrawal pending. Check your wallet for queued transactions and confirm that you are using the same account that started the transfer. Polygon Support says the Portal may show a “Try Again” button after an hour for some stuck transactions. Use it only when the Portal offers it for that withdrawal.

Before signing another transaction, check the hash and status again. A retry or replacement can create a new transaction, so confirm which one is active in your wallet. Do not share your recovery phrase or approve a transaction sent by someone claiming to be support.

How do I complete an exit on Ethereum?

If the Polygon-side transaction succeeded but the Ethereum step is incomplete, Polygon Support says its pending-withdrawal tool can help complete the exit. It instructs users to paste the transaction hash and select “Confirm Exit.” Use the tool reached from Polygon’s own support guidance or Portal, and check the selected network and transaction details in your wallet before signing. The exit may require an Ethereum transaction and a network fee.

The Portal also has a withdrawal tool for older transfers initiated before January 1, 2024. Its instructions ask for the Polygon burn transaction hash and a final Ethereum transaction. That tool is for the older transfers it specifies; it is not a general fix for every current withdrawal.

When should I contact Polygon Support?

Contact Polygon Support if the source transaction is confirmed but the Portal cannot find the withdrawal, the exit fails, or the status remains unclear after checking the hash. Include the source transaction hash, the networks involved, the wallet address and a screenshot of the error. Never send a seed phrase or private key. The practical rule is simple: verify the last completed step, then use the Portal’s retry or exit option that matches it.
