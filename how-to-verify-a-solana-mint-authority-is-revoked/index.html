How to Verify a Solana Mint Authority Is Revoked

To check if Solana mint authority has been revoked, read the exact mint’s decoded field: None or null means absent; a public key means it remains assigned.

The Chain Times DeskNov 19, 2026 · 00:44 UTC3 min read

Open the token’s exact mint account in Solscan first; every later conclusion depends on reading the right account. A Solana mint authority is revoked when that account’s decoded mint authority field reads None or null, because the mint account stores the permission to create more tokens.

A rugcheck is a token risk check that reviews warning signs of a possible scam or rug pull. Take rugcheck LP locked as an example: the LP lock signal is useful because it concerns liquidity, while the mint field tells you whether an authority remains assigned. Treat them as separate checks.

Read the mint authority on the exact account

The mint account’s decoded authority field shows whether the mint authority is absent or still assigned.

  1. Start with the token to investigate. Get its exact mint address. A token name or ticker alone may not identify the mint you intend to check. Paste the address into Solscan and open the matching mint account. Confirm the address shown in the account is the same one you entered.
  2. Find the decoded mint authority. Read the field labeled “Mint authority” in the account’s decoded information. The mint account stores this permission, so this field is the direct evidence for the authority state. Read the value itself, not just a summary label elsewhere on the page.

Compare the field with the risk finding

Compare rugcheck’s authority finding with the mint field, and read freeze authority as a separate permission.

  1. Interpret the value carefully. None or null means no mint authority is assigned. A public key means an authority remains assigned. That key could belong to a person, a program, or an address someone describes as a burn address. Even if a public key is called a burn address, its presence in the field is not the same as revocation: actual revocation removes the authority from the field. Solana’s mint specification makes the authority optional, and the SetAuthority instruction can permanently remove it.
  2. Finish by checking the visible state. If rugcheck reports that the mint authority is revoked, compare that claim with the exact mint’s decoded field. None or null confirms the authority is absent; a public key means it remains assigned, even if the address is presented as a burn address. If the findings differ, rely on the mint field for the observed authority state and make sure you have the intended mint. Read the freeze authority separately: it is another authority field, so its value does not change what the mint authority field says.
