Token allowance vs token balance: ERC-20 accounting

Token allowance vs token balance: a balance is what an address holds; an allowance is a spender’s remaining authority over those tokens under an ERC-20 contract.

The Chain Times DeskNov 18, 2026 · 15:10 UTC3 min read

Token allowance vs token balance: a balance is what an address holds, while an allowance is a named spender’s remaining authority over that owner’s tokens in one ERC-20 contract.

An ERC-20 contract keeps these amounts separately. Its balanceOf(owner) function returns the tokens held by an address. Its allowance(owner, spender) function returns how much that spender is still authorized to spend for the owner. The contract’s transferFrom function lets the spender move tokens within that permission.

When reviewing approvals in revokecash, compare the token amount held with each spender’s remaining permission; the [revokecash approval view](https://revoke.cash/learn/approvals/how-to-revoke-token-approvals) helps you inspect and change approved amounts. The balance shows what is in the account, while each allowance shows a separate route for a contract to spend it.

ERC-20 balances stay separate from spender permissions

ERC-20 allowances do not reserve or lock tokens. Say an address holds 100 tokens and authorizes two spenders for 60 each. The balance remains 100, and both allowances can remain 60 at the same time. The total authorized amount is 120, even though the wallet holds only 100.

If the first spender transfers 60 using transferFrom, the owner’s balance falls to 40. The first spender’s allowance is reduced by the transfer, while the second spender’s 60-token allowance remains. That second spender cannot transfer more tokens than the owner has available. The permission amount and the available balance answer different questions.

This distinction matters when assessing approval exposure. A large allowance is permission the spender can use, subject to the balance and the token contract’s rules; it is not a record of tokens already moved. Reducing an allowance changes the spender’s authority, while the tokens the owner holds remain in the account. The [revokecash approval page](https://revoke.cash/learn/approvals/how-to-revoke-token-approvals) explains how to review and change approved amounts.

Compare amounts in the token itself, then consider which spenders still have permission. A balance of zero can coexist with a nonzero allowance, and tokens received later may then be within that permission. Conversely, a positive balance does not by itself show that any spender can move it.

Related questions

Does token allowance expire?

A standard ERC-20 allowance has no built-in expiry time. It remains until it is spent or changed; token-specific extensions can differ. The ERC-20 standard defines the balance, allowance and delegated transfer interfaces.

Is allowance expressed in dollars?

No. The contract records token amounts in base units, and interfaces apply the token’s decimals to display them. Compare the displayed balance and allowance for the same token, rather than treating either contract value as a dollar amount.

Next, review each spender’s allowance alongside the balance for that token. Reduce permissions you no longer need, and you’ll have a clearer view of what is held and what each approved spender can still move.
