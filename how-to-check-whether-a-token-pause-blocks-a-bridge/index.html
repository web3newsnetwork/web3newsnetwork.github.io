How to Check Whether a Token Pause Blocks a Bridge

A token pause can stop a bridge deposit or payout even when a route is listed; check the exact token, chain pair and transaction before sending.

The Chain Times DeskOct 16, 2026 · 09:43 UTC3 min read

A token pause can block a bridge route if it stops the transfer or mint the route needs. Check the exact token contract on the sending chain, then check the bridge’s support for that chain pair and token. A route listing is useful, but it does not prove that a paused token can move. For a separate look at timing, see Acrossbridge treasury transfer timing.

What does a token pause stop?

A pause is a rule in a token contract that can block some or all token actions. OpenZeppelin’s ERC20 Pausable reference describes an example that pauses transfers, minting and burning. Other tokens may use different rules, so the word “paused” alone does not tell you which actions are blocked.

For a bridge deposit, the token usually has to move from your wallet to a bridge contract. If the pause blocks that transfer, the transaction may fail before the bridge receives anything. On the destination chain, a bridge may need to release or mint tokens; a pause that blocks that action can prevent payout. The bridge itself may also pause a route. That is a separate control from the token’s pause.

How can you check whether the route is available?

Check the route with the exact origin chain, destination chain, input token and output token. Across’s documentation says support depends on the chain pair and tokens, not just whether a chain is supported. Its route data lists accepted input tokens and route limits. A route that is missing or no longer offered cannot be treated as available.

  • Confirm the token’s contract address on the sending chain. Symbols and names can be copied by unrelated tokens.
  • Check the token’s official status notice and contract details for a pause or transfer restriction.
  • Use the bridge’s current route page or quote for the same chain pair and token addresses.
  • Read any wallet simulation or transaction error. A failed transfer call can indicate the token rejected the action.

Does a quote prove the transfer will work?

No. A quote shows that the bridge currently offers a route under the details entered. It is not proof that the token contract will accept your transfer when you submit it. A pause could change, or a token rule could reject a specific action. A successful wallet simulation is a useful check, but it cannot guarantee later execution.

Before sending, compare the token address in the quote with the one in your wallet and verify the chain pair. If the token is paused or the transaction simulation fails, wait for a clear status update from the token issuer or bridge. Do not try a different token with the same name as a workaround. The practical test is whether the exact token can complete the exact transfer the route requires.
