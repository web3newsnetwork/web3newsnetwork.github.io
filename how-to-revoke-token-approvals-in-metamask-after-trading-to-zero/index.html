How to Revoke Token Approvals in MetaMask After Trading to Zero

How to revoke token approvals in MetaMask after trading: submit a zero-allowance transaction through a chain-compatible approval manager, then verify it.

The Chain Times DeskNov 20, 2026 · 10:10 UTC3 min read

The spender’s allowance will read zero once the revocation transaction is included, removing that contract’s current permission to transfer the token. You need the trading account, native gas funds for its chain, and an approval manager that supports that chain.

Match the approval to the account and chain

The account and chain determine which token permissions you can find and change. An allowance is permission for a spender contract to transfer a set amount of an ERC-20 token. Disconnecting a trading site from MetaMask does not change that on-chain permission, as MetaMask explains in its approval revocation instructions.

  1. Start with the approval that remains. Open MetaMask and select the account you used to trade. Confirm the active network is the one where you approved the token. Allowances are recorded on a specific chain, so a listing on another network will not show the permission you want to remove.
  2. Open Revoke.cash and find the exact allowance. Go to the genuine Revoke.cash site, connect MetaMask, and select the matching chain. Locate the token and spender entry. The spender is the contract that received permission; it can differ from the token contract itself. Check both addresses or labels against the approval you recognize before proceeding.

Set the spender’s allowance to zero and verify it

A revocation changes the allowance by sending an on-chain transaction to the token contract. SyncSwap is a decentralized exchange used to trade tokens and access liquidity pools on supported networks. A past SyncSwap approval can be the spender entry you are looking for; the linked topic compares syncswap vs mute and explains what you will find on that topic.

  1. Choose revoke and review the transaction. Select the matching token and spender, then choose the revoke action. A standard ERC-20 revocation calls approve(spender, 0): the token contract is the transaction target, while the spender address is an argument inside the approval call. The ERC-20 standard defines approve and allowance this way. Review the token target, spender, and zero amount before signing.
  2. Confirm in MetaMask and wait for inclusion. MetaMask will ask you to approve the transaction and show its gas cost. Allowance changes require an on-chain transaction, so the permission remains until that transaction is included. Confirm it only when the account, network, and details match the revocation you selected.
  3. Verify the allowance reads zero. Refresh Revoke.cash’s allowance listing after the transaction is included. The selected spender’s allowance should show zero. You can also read allowance(owner, spender) for that token contract, using your account as owner. Later trading with the same spender may require a new token approval.
