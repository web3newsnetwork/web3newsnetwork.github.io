Match the crypto network before you send

Match the coin, network and any required memo to the exchange’s deposit instructions before sending, because a transfer on an unsupported network may not arrive.

The Chain Times DeskOct 16, 2026 · 19:10 UTC3 min read

To send crypto to an exchange, choose the same network on the sending and deposit screens. A token such as USDT may be available on several networks, but the exchange only credits deposits it supports for that token. Its deposit page is the source to follow for the address and network.

A network is the blockchain that carries a transaction. Sending USDT over Ethereum and sending USDT over another chain are different transfers, even though the token name is the same. Exchange help pages from Crypto.com and Coinbase tell users to check network support before sending. A bridge can move assets between chains, but its route depends on what needs to arrive; this guide to ParaSwap bridge routes explains that choice in more detail.

How do I choose the right deposit network?

Open the exchange’s deposit page, select the coin, then note the network shown for that deposit. On the sending exchange or wallet, select that same network. Coinbase’s deposit instructions, for example, say to choose the network associated with the deposit address; Crypto.com says the selected networks must match.

Check that the exchange supports both the asset and network you plan to use. An exchange may list a coin but not accept it on every chain where it exists. A familiar address format does not prove the network is right. Follow the network label on the deposit page, not a guess based on how the address looks.

What should I check before sending?

Compare the deposit instructions with the withdrawal screen before confirming. Check these details:

  • Asset: Select the exact coin or token the exchange lists.
  • Network: Match the network name on both screens.
  • Address: Copy the address from that deposit page and check its beginning and end after pasting.
  • Memo or tag: If the exchange provides an extra identifier, enter it in the sending form too.

Some exchanges use a memo or tag to direct a deposit to a specific account. Bitso’s XRP instructions, for example, say an exchange transfer needs a destination tag for the funds to be credited. The receiving exchange’s deposit page tells you whether one is required.

Should I send a test transfer first?

A small test can help confirm that the details work before you send a larger amount, but it does not replace checking the network. Coinbase Exchange suggests a test deposit to check that the asset is supported and the address is saved correctly. Check any minimum deposit and network fee first, since a test may cost money and could fall below the exchange’s crediting threshold.

Once a transfer is broadcast, it usually cannot be canceled through the sending wallet. Coinbase warns that funds sent to an unsupported or incorrect network may be lost, and recovery is not guaranteed. Save the transaction hash—the transfer’s reference on the blockchain—if the deposit takes longer than the exchange says to expect. The practical rule is simple: use the exchange’s current deposit instructions, match the asset and network, then verify any extra fields before sending.
