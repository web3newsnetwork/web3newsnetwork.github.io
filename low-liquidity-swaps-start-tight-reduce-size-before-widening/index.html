Low-liquidity swaps: start tight, reduce size before widening

What slippage tolerance should you use for a low-liquidity token swap? Start tight, then widen only as needed—or cut the trade size or compare pools.

The Chain Times DeskNov 26, 2026 · 16:04 UTC3 min read

For a low-liquidity token swap on SunSwap, start with a tight slippage tolerance and widen it only enough to allow for likely price movement.

On SunSwap, you swap TRC-20 tokens through a liquidity pool on TRON. Your quote estimates what you will receive; the tolerance sets how far the final output can fall before the swap reverts. For more on how SunSwap sets a swap’s minimum output, see our explanation of the setting and its floor.

How does tolerance affect a thin-pool swap?

A shallow pool has fewer reserves to absorb your trade, so a large order relative to those reserves can move the pool price and raise price impact. Price impact is the change caused by your own trade. A wider tolerance lets the swap complete at a lower output; a tighter one protects more of the quoted amount but can cause a revert if the price moves before confirmation.

Say a quote offers 1,000 tokens. At 1% tolerance, the minimum output is 990 tokens. That is the lowest output the swap would accept under that quote and setting, not a recommended tolerance. The quote and tolerance together determine the floor; if execution falls below it, the swap reverts.

There is no universal safe percentage. The right setting depends on pool depth, trade size, token volatility and how long confirmation takes. Start tight, review the quote and price impact, then widen the tolerance only if needed to accommodate likely movement before confirmation.

What should you change when a low tolerance fails?

When a low tolerance fails, first compare quotes at several trade sizes against the same pool. If a smaller order gives you more output per token, reduce the order before widening tolerance. The trade is moving the pool price; accepting a worse minimum output would not fix that price impact.

Take an illustrative case: your original order has a lower output per token than a smaller one from the same pool. Reducing the order changes the amount you trade and can improve the output per token. The pool stays the same, and the price impact can fall because your order uses less of its reserves. If the smaller size still needs an uncomfortable tolerance, compare a deeper pool or another route before proceeding.

Related

Can I split a low-liquidity swap into smaller trades?

Splitting may help when smaller orders get better output per token from the same pool. Compare the quotes first: the pool can still move between trades, so splitting does not guarantee a better total output.

Does slippage tolerance change the quoted price?

No. Tolerance sets the minimum output you will accept from the quote. A wider setting permits a lower final output; it does not improve the quoted price.
