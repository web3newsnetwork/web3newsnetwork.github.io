How to check a cross-chain swap after sending it

After sending a cross-chain swap, check the source transaction, follow its status, then confirm the outgoing transfer and token on the destination chain.

The Chain Times DeskOct 15, 2026 · 20:14 UTC3 min read

To check a cross-chain swap after sending it, follow the deposit on the source chain and then verify the outgoing transfer on the destination chain. A swap can involve more than one transaction, so a confirmed deposit does not by itself prove the funds arrived. Start with the transaction hash in the swap app or wallet and open it in an explorer for the chain you sent from.

What should I check first?

Check that the source transaction is confirmed and that its destination address matches the address shown by the swap app. A transaction hash is the unique ID for that transaction; a block explorer shows its status, sender, recipient and included block. Ethereum.org describes these as standard explorer details. If the transaction is pending, the swap may not have reached the service or network that handles the next step. If it failed, check the wallet or app for the reason before trying again.

Once the deposit is confirmed, the swap still needs to be processed and sent on the other chain. The stages and wait time vary by service and network conditions. For more on how congestion can affect timing, see thor swap. The THORChain documentation, for example, describes delayed outbound transfers as a separate stage to track.

How do I confirm the swap reached the other chain?

Look for an outbound transaction ID in the swap app’s status page or tracker. Open that ID in an explorer for the destination chain. Check that the recipient is your wallet address, the token is the one you expected, and the transaction status shows success. A successful source deposit and a successful destination transfer are separate checks.

Compare the amount received with the quote shown before you sent the swap. The final amount can differ because of the quoted rate, fees or a change in the rate while the swap was processed. The explorer shows what reached your address; the swap app can help explain how that amount was calculated.

What should I do if the swap is still waiting?

Use the source and destination transaction IDs to work out which stage is waiting. If the source transaction is confirmed but there is no outbound ID yet, check the swap app’s tracker for an update. If an outbound ID exists, the destination explorer can show whether that transaction is pending, failed or confirmed. A slow or congested network can hold up one stage while the other has already finished.

  • Save the swap’s reference number and both transaction IDs.
  • Check each ID on the explorer for its own chain.
  • Confirm the destination address and token before treating the swap as complete.
  • If the app reports a failure or the tracker stops updating, contact that service’s support with the reference number.

Use only the swap app and public explorers to check progress. No support agent needs your wallet recovery phrase or private key. The practical test is simple: confirm the deposit, then confirm the outbound transaction and the asset in your destination wallet.
